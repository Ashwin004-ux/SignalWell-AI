How SignalWell works

  1. 1. Collect

    The extension records browser activity; you log sleep and mood.

  2. 2. Aggregate

    Each day's activity is summarized into consistent daily figures.

  3. 3. Analyze

    An AI layer looks for relationships across your recent history.

  4. 4. Reflect

    You see plain-language insights and suggestions, not a diagnosis.

AI insights, written plainly

The extension

A Manifest V3 browser extension records which domains you visit and for how long, including social media and late-night use. It never reads page contents, keystrokes, form data, or messages. You can pause tracking at any time from the extension popup.

Frequently asked questions

Does SignalWell diagnose mental health conditions?

No. SignalWell identifies patterns in your data and produces wellbeing indicators — stable, monitor, or elevated — not clinical diagnoses. It is not a substitute for a qualified mental health professional.

How does the extension collect data?

The browser extension records domain-level usage (which sites, how long, and when) using Chrome's Manifest V3 APIs. It does not read page contents, form data, or messages.

Can SignalWell read my screen time on my phone or laptop OS?

Not directly — a website cannot access operating-system-level screen time. Today, SignalWell measures browser activity through the extension and whatever you choose to log yourself. Device-level integration is planned as a separate, explicitly-permissioned component.

Who can see my data?

Only you. Every table in the database is isolated with Supabase Row Level Security, so no other user or generic backend process can query your rows.
